## Описание

Сайт центра, который лечит раненых диких птиц и возвращает их в природу. Посетитель может:

- посмотреть подопечных центра: хищных, певчих, водоплавающих и городских птиц;
- открыть подробную страницу каждой птицы с историей, ходом лечения и прогнозом;
- оставить заявку на опеку или забрать домой птицу, которая не сможет жить на воле;
- узнать, что делать, если нашёл раненую птицу;
- помочь центру деньгами, кормом или волонтёрством.

Обязательная структура КР №2 сохранена: главная, каталог, карточка, заявка. Вместо товаров здесь птицы, а вместо заказа — заявка на опеку или пристройство.

Bootstrap 5.3.8.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN. Файлы фреймворка лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap, чтобы переопределять отдельные стили.

## Самостоятельные доработки

1. **Фильтр и сортировка каталога.** Кнопки «Все / Хищные / Певчие / Водоплавающие / Городские» (`btn-group` + `btn-check`), сортировка по возрасту и счётчик «Найдено». Реализовано в `js/main.js`, у карточек есть атрибуты `data-type` и `data-age`.
2. **Страница «Помочь центру» (`help.html`).** Сборы с полосами `progress`, вкладки `nav-pills`, список нужных вещей на `list-group`, модальное окно с анкетой волонтёра. На странице контактов есть инструкция «Нашли раненую птицу?».
3. **Отдельная страница у каждой птицы и подстановка в заявку.** Кнопка «Подробнее» ведёт на страницу конкретной птицы. Кнопка «Помочь …» открывает `order.html?bird=bella`, и скрипт сам выбирает птицу в списке и показывает `alert`. Все формы проверяются через `was-validated` / `invalid-feedback`, после отправки показывается `toast`.
4. **Светлая и тёмная тема с анимацией.** Кнопка в навбаре переключает атрибут `data-bs-theme`, встроенный в Bootstrap 5.3. Выбор сохраняется в `localStorage`.
   Смена темы анимирована. При переходе в тёмную тему пиксельная птица летит слева направо и тянет за собой ночное небо («наступает ночь»). При переходе в светлую она летит справа налево и открывает экран («наступает утро»). Крылья машут за счёт спрайта из двух кадров, движение рассчитывается через `requestAnimationFrame`. Если в системе включено «уменьшение движения» (`prefers-reduced-motion`), тема меняется без анимации.

5. **Раздел «О нас» на главной (`index.html#about`).** Описаны цель центра, роли ветеринаров, волонтёров и опекунов, принцип возвращения птиц в природу. Есть переходы к волонтёрству и контактам. Раздел адаптирован для мобильных устройств и обеих тем.
6. **Упрощённая единая навигация.** На всех 13 страницах меню содержит «Подопечные», «О нас», «Помочь», «Контакты» и переключатель темы. Логотип ведёт на главную, карточки птиц и заявки доступны через каталог и контентные кнопки. В подвале добавлена ссылка «О нас». Эмодзи в блоке «Как мы работаем» увеличены в 1,5 раза относительно адаптивного размера Bootstrap `.fs-2`.

Также:

- Bootstrap подключён локально из `vendor/`;
- у каждой страницы своё meta description;
- проект опубликован на GitHub Pages.

## Как проверить

1. Открыть ссылку GitHub Pages или `index.html`.
2. Нажать «🌙 Тёмная»: птица закроет экран ночным небом. Нажать «☀️ Светлая»: птица откроет его обратно. Обновить страницу — тема должна сохраниться.
3. В `catalog.html` нажать «Водоплавающие»: должно показаться 2 птицы. Выбрать «Сначала взрослые».
4. Нажать «Подробнее» у любой птицы: откроется её страница. Нажать «Помочь …»: в заявке эта птица уже выбрана.
5. Отправить пустую форму, проверить подсветку ошибок, затем заполнить форму и проверить toast.
6. На странице птицы переключить вкладки, раскрыть accordion, открыть модальное окно «Экскурсия».
7. В `help.html` открыть вкладку «Волонтёрство» и анкету волонтёра.
8. Проверить адаптивность в DevTools на ширинах 375, 768, 1024 и 1440px.
9. Открыть «О нас» из меню каталога: должен открыться раздел на главной. Проверить ссылки «Стать волонтёром» и «Связаться с нами», затем мобильное меню и тёмную тему.

## Ограничения демонстрационной версии

Проект — статический frontend для КР №2. Контакты и показатели приведены для демонстрации. Формы проверяют ввод и показывают уведомление, но не отправляют данные на сервер. Перед реальным запуском нужно указать подтверждённые контакты и реквизиты центра, подключить обработку заявок и подготовить документы об обработке персональных данных.
