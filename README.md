## Описание

Сайт небольшого приюта для животных. Посетитель может посмотреть каталог питомцев (кошки, собаки, кролик, попугай), открыть подробную страницу питомца, оставить заявку на пристройство, записаться на знакомство или помочь приюту.

Вместо товаров здесь питомцы, а вместо заказа — заявка на пристройство. Обязательная структура КР №2 сохранена: главная, каталог, карточка, заявка.

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN. Файлы фреймворка лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap, чтобы переопределять отдельные стили.

## Самостоятельные доработки

1. **Фильтр и сортировка каталога.** Кнопки «Все / Кошки / Собаки / Другие» (`btn-group` + `btn-check`), сортировка по возрасту и счётчик «Найдено». Реализовано в `js/main.js`, у карточек есть атрибуты `data-type` и `data-age`.
2. **Страница «Помочь приюту» (`help.html`).** Сборы с полосами `progress`, вкладки `nav-pills`, список нужных вещей на `list-group`, модальное окно с анкетой волонтёра.
3. **Подстановка питомца в заявку.** Кнопка «Хочу забрать» ведёт на `order.html?pet=barsik`, и скрипт сам выбирает питомца в списке и показывает `alert`. Все формы проверяются через `was-validated` / `invalid-feedback`, после отправки показывается `toast`.
4. **Светлая и тёмная тема.** Кнопка в навбаре переключает атрибут `data-bs-theme`, встроенный в Bootstrap 5.3. Выбор сохраняется в `localStorage`. Цвета заданы через `bg-body`, `bg-body-tertiary`, `text-body-secondary` и `*-subtle`, поэтому в обеих темах всё читается.

## Как проверить

1. Открыть ссылку GitHub Pages или `index.html`.
2. Проверить навигацию, выпадающее меню и кнопку «🌙 Тёмная», затем обновить страницу: тема должна сохраниться.
3. В `catalog.html` нажать «Кошки» и выбрать «Сначала взрослые»: должно показаться 3 питомца, первым Рыжик.
4. Нажать «Хочу забрать» у любого питомца: в заявке он уже выбран.
5. Отправить пустую форму, проверить подсветку ошибок, затем заполнить форму и проверить toast.
6. В `product.html` переключить вкладки и раскрыть accordion, нажать «Познакомиться»: откроется модальное окно.
7. В `help.html` открыть вкладку «Волонтёрство» и анкету волонтёра.
8. Проверить адаптивность в DevTools на ширинах 375, 768, 1024 и 1440px.
