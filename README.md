## Описание

Проект представляет собой учебную версию сайта интернет-магазина электроники, разработанную с использованием Bootstrap.
КР №2 не является адаптацией КР №1: это отдельная реализация той же предметной области через CSS-фреймворк.

## Ссылка на опубликованный проект

**GitHub Pages:** https://f1shi.github.io/kr2-bootstrap-shop/

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

В проекте Bootstrap подключён локально. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap, чтобы переопределять отдельные стили.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** без CDN из папки `vendor/bootstrap/`.
2. **Страница контактов** `contacts.html` с формой обратной связи.
3. **Carousel** с акциями на главной странице.
4. **Tabs** на странице товара: характеристики, доставка, отзывы.
5. **Pagination** в каталоге.
6. **Toast** с сообщением об успешной отправке формы.
7. **Bootstrap-валидация форм** через `was-validated` и `invalid-feedback`.
8. **Расширенный каталог** из шести товаров с разными значками.
9. **Уникальные meta description** на каждой странице.
10. **Публикация через GitHub Pages.**

## Как проверить

1. Открыть ссылку GitHub Pages или файл `index.html` в браузере.
2. Проверить навигацию и выпадающее меню.
3. Открыть `catalog.html`, нажать «Заказать» и проверить модальное окно.
4. Открыть `product.html`, переключить вкладки и раскрыть accordion.
5. Открыть `order.html`, отправить пустую форму и проверить подсветку ошибок, затем заполнить форму и проверить toast.
6. Проверить адаптивность в DevTools на ширинах 375, 768, 1024 и 1440px.
